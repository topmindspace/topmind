# Desktop 功能、性能与交互整改

首轮日期：2026-10-24；续轮：2026-10-25。基于当前工作树审查，保留审查前已有改动。以下记录本轮实现与证据，不表示全产品、真实模型或三平台安装包已全面验收。

编辑器、源码模式与 Obsidian 内容往返的后续整改见 [2026-10-25 编辑器兼容记录](DESKTOP-EDITOR-COMPATIBILITY-2026-10-25.md)。

## 审查依据与取舍

- [Electron 性能指南](https://www.electronjs.org/docs/latest/tutorial/performance)：根据运行行为定位瓶颈，减少重复工作与不必要的网络请求。本轮处理模型目录请求合并、过期请求停止、流式监听与动画帧释放；不凭代码缩短宣称整机加速。
- [WCAG 2.2 状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)：搜索的加载、结果数与错误应被辅助技术感知，同时保留当前输入焦点。本轮增加状态播报、错误重试，并修复显示顺序与键盘顺序不一致。
- [Anthropic 上下文工程](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)：上下文应有相关性、边界和预算。本轮先修读取边界与会话隔离；按意图进一步裁剪画像、概览，需要真实任务评测后推进。
- 产品继续使用 [Desktop 设计规范](../topmind-desktop/DESIGN.md) 的安静工作台、渐进展示与可中断 AI。保留本地文件真源、自然语言入口和既有写回授权语义。

## 已落地

| 优先级 | 已确认问题 | 整改与执行证据 |
|---|---|---|
| P0 | 损坏的聊天 JSON 被当成空历史；下一次发送可能覆盖旧记录 | `AiService.loadMessages` 仅对文件不存在返回空数组，解析和非数组格式错误向上传递；真实服务测试验证原始字节保留；界面提供重试并保留输入草稿 |
| P0 | 专题 ID 路径穿越、专题/画像符号链接可将工作区外内容送入模型 | 上下文预取复用真实路径围栏，校验专题两段结构；测试覆盖目录/文件链接越界、画像越界及工作区内合法链接 |
| P1 | 先发后至的历史请求覆盖后来选中的对话，旧读取失败也可能清空新对话 | 会话选择与历史加载使用独立请求代次；仅当前会话接收结果；加载中暂停发送，失败可重试 |
| P1 | 新建/清空会话未统一释放旧流；暂停/取消的迟到响应可能清除新回合状态 | 先终止旧流并释放监听、动画帧；取消与暂停的清理仅作用于本代次；暂停保留已收到的文字 |
| P1 | 工作区释放后，旧请求仍可能回填会话列表、消息或完成结果 | 释放时同时使工作区、流、会话选择和历史请求失效，终止旧流并清理挂载文件、技能与队列 |
| P1 | 最终结果落到消息后，尚未刷新的增量再次追加；持久化可能漏最后一批文字 | 先刷新增量，再接收终态并保存；测试分别验证完整终态与空终态回退，断言界面和保存内容一致 |
| P1 | 后端暂不能接收补充时，前端只显示排队计数，未保存补充内容 | 增加真实本地后备队列，成功回合后依次执行；会话切换/取消使旧补充失效；执行测试验证多条补充顺序 |
| P1 | 搜索分组显示顺序与键盘索引不同，筛选后仍按全量结果移动；按键可能传播到下层导航 | 分组、连续索引与打开动作共用同一份有序结果；键盘仅在当前可见结果内移动；已处理的 Enter/方向键不传播，输入法仍保持原生提交 |
| P1 | 清空关键词/关闭搜索后旧请求仍可能回填；失败显示成无结果 | debounce 与已发请求共用生命周期清理；失败独立显示并可重试；切工作区使请求失效 |
| P2 | 同时刷新模型目录会重复读取目录并请求提供商和社区列表 | 同等刷新合并为一个请求；更强的手动刷新仍执行；设置失效后旧结果不发布，也不继续启动后续网络请求 |
| P2 | 搜索结果刷新时，静止指针下方的行可能改变键盘活动项 | 只在鼠标实际移动时更新悬停选中；保留输入法组词 Enter、Home/End 原生文本编辑行为 |
| P2 | 搜索路径与预览正文仅 12px，加载/结果数缺少稳定播报 | 正文提升到既有 13px 档；增加独立状态区域与列表 busy 状态；不对整段流式 AI 回复逐字播报 |
| P2 | 轻量闲聊仍构造全部工具、读取挂载文件和画像，并注入技能目录与目标协议 | 提前按既有回合分类准备资源；闲聊跳过上述准备并使用简短提示；查询与任务保留资源，独立准备并行执行 |
| P2 | 空工作区侧栏和主画布重复大空态与捕获动作 | 侧栏改为两行紧凑提示；保留主画布首次输入和 ActivityBar 完整捕获入口 |

实现主要位于 `src/stores/ai-store.ts`、`src/lib/workspace-search.ts`、`GlobalSearch.tsx`、`AiPanel.tsx`、`ChatInput.tsx`、`electron/ai-service.mjs` 与 `electron/lib/ai-context-loader.mjs`。

## 2026-10-25 架构与工作台续改

保留本地文件真源、既有写回授权与 Pi/AI SDK 运行链路。此次按职责提取会话存储和纯布局契约，取消仍由现有 stream registry 统一持有；没有另建流程框架或会话数据源。模型效果是否更好仍需真实任务评测。

| 问题 | 整改 |
|---|---|
| 会话只在回合结束保存，暂停快照不能重载继续 | 模型调用前先保存用户请求；暂停/取消保存最新快照；重新打开暂停会话恢复文字、目标与继续入口 |
| 保存错误可能替换成功回答，离开会话时静默丢失最新内容 | 显示保存失败与重试入口，保留当前回答；切换/新建前重试，仍失败则保留原会话。明确清空仍可丢弃记录 |
| 会话元数据并发覆盖、保存与清空竞争，直接覆盖 JSON 可能留下半截数据 | `ai-session-store.mjs` 统一按工作区排序；消息、索引与检查点写同目录临时文件，同步、关闭后原子替换；失败保留上一份完整文件、清理临时文件，队列继续处理 |
| 设置保存的异步清理可能删除下一次保存刚创建的空临时文件，导致 rename ENOENT | 跟踪并保护活动临时文件、使用唯一文件名、失败时清理残留；确定性测试在文件创建与首次写入之间触发真实清理，先复现再修复 |
| AI 准备阶段尚未登记流句柄，取消后仍可能启动模型 | 入口先预留 invocation scope；准备、模型流与完成评审共用取消生命周期。旧 scope 不能注册覆盖新流或取走新流队列 |
| 两栏各自允许最大宽度，最小窗口的内容画布可能被挤没 | 设置、store 与 Shell 共用 `workbench-layout.mjs`；至少 1180px 的正常桌面视口保护 400px 画布；自动适配不覆盖宽度偏好 |
| 分隔条以包含 ActivityBar 的父边缘计算，首次拖动会跳变且逐次读取布局 | 使用拖动起点与位移计算，支持受控组件更新、键盘、边界和失焦释放 |
| 高缩放下自动隐藏的侧栏无法通过原快捷键打开，专注模式中的打开聊天无可见结果 | 按钮与快捷键共用 store 动作；空间不足时导航让 AI 列让位，显式打开聊天/导航退出专注模式 |
| 200% 缩放时动态输入卡片的润色/记下操作组超出边缘，部分主按钮被裁切 | 操作组限制最大宽度并允许换行；实际 DOM 边界测试先复现超出约 39px，再验证按钮留在卡片内 |
| 手写标签页缺少完整键盘语义，窄 AI 栏截断名称，高缩放后缺少可访问名称 | 复用 Radix Tabs chrome 变体；方向键、Home/End、单一 Tab 停靠点及面板关联统一维护。按 AI 列容器宽度显示文字，图标始终有名称与 Tooltip；Composer 保持挂载 |

删除旧服务内重复的会话文件操作、前端重复的暂停/取消实现和分散的尺寸校验；清理源码计数测试中的历史注释墙。旧视觉契约改为检查共享 Tabs 所在的职责位置，没有为了匹配旧正则恢复重复实现。架构、设计文档与实际源码计数同步。

写回策略文档守卫不再匹配已删除的 UI 注释，改为校验 Desktop 快照与 Kernel `lib/agent-policy.mjs` 一致；分级确认的执行语义继续由现有行为回归覆盖。

新增与扩充的执行测试覆盖真实 store、服务和分隔条：预先保存、暂停重载、初次/最终保存失败、重试、准备阶段取消、旧流隔离、并发元数据、清空竞争、原子替换失败后字节保留及恢复、最小视口与高缩放导航。原子替换回归先确认旧实现失败，再通过整改。

真实 macOS Electron 使用临时工作区与本机合成 SSE 服务，验证中英文搜索、深色界面、标签键盘与草稿、分隔条实际拖动，以及以下边界：

- 实际 1180px 视口、宽度偏好 480/800px 时，展示侧栏 450px、画布 400px、AI 栏 280px；保存偏好仍为 480/800px。
- 侧栏偏好 180px 时，AI 栏在 1180px 视口展示 550px，放大到 1440px 后恢复 800px。
- 200% 缩放后 CSS 视口为 590px，侧栏自动让出空间；按钮和 ⌘B 均能打开导航。
- 窄 AI 列的页签保留独立可访问名称与 Tooltip；200% 缩放下，动态输入卡片操作按钮均留在卡片边界内，实际点击 Log it 后内容已写入动态 Markdown 并显示。
- 用户请求在合成模型返回完成前已保存。真实只读目录导致暂停快照保存失败，界面显示重试且原文件字节不变；恢复写权限后重试成功，重载可继续暂停会话。

本轮最终 `npm run validate` 通过：Kernel/跨表面 692 项、UTR 151 项、Desktop 1,461 项 `.mjs` + 67 项 TypeScript 测试；密钥扫描、文档、共享契约同步、类型、语法、未声明标识符、死代码、双语、构建和打包源码检查通过。并行更新后的资源快照已重新生成并校验，未修改发布版本或生成发行安装包。最终 Electron 10 组流程通过，未捕获 renderer error，测试服务和进程已关闭。

这些检查未使用生产凭据或付费模型；不代表断电事务、多进程并发、全程实时快照或真实模型任务成功率已经验证。

## 后续按价值推进

1. **真实模型效果与成本**：中英文、查询/写入、跨技能、暂停/恢复、失败恢复任务集；记录输入 token、首次响应、完成率、额外确认、成本和失败 trace。再决定 goal/evaluator 与预取上下文的裁剪，不能用静态提示词测试代替模型效果。
2. **大工作区性能**：真实文件规模下记录冷启动、搜索 P95、主进程阻塞、内存峰值、长对话滚动与后台唤醒；查询与任务仍预取概览和画像，应依据测量决定进一步按需加载与缓存失效方案。
3. **主路径体验**：用真实工作区复核捕获→加工→编辑→交付→找回，覆盖键盘、缩放与屏幕阅读器。先验证任务完成率与可发现性，再调整视觉结构。
4. **失败与续跑**：进一步完善失败回合后的排队补充保留，验收进程退出、网络断开与跨重启续跑；暂停快照已可重载，本地后备队列仍只覆盖当前进程，不承诺进程崩溃后恢复。
5. **发行验收**：macOS/Windows/Linux 真实安装包的安装、升级、权限、窗口菜单、输入法和可访问性。当前 `pack:verify` 没有发行安装包，源码检查不替代这一步。
