# 写作与 AI 工作流体验整改

日期：2026-10-28。这是当日路径记录，不是现行规格。现行交互以 Desktop 与 Obsidian 的 DESIGN.md 和产品 README 为准。实现与版本以各仓代码、测试及发行清单为准。

## 先看用户要做什么

| 用户目标 | 最短路径 | 完成标志 |
|---|---|---|
| 随手记一条 | 明确的新建/速记入口 → 输入 → 保存 | 新笔记立即打开，可继续编辑；回执给真实路径 |
| 用当前笔记写稿 | 当前笔记的「写作」入口 → 选目的 → 明确开始 | 任务绑定这篇笔记；结果或错误留在可见位置 |
| 只排版交付 | 当前笔记 → 排版预览 → 复制或导出 | 不触发 AI；预览和复制来自同一份产物 |
| 对选中文字提问或改写 | 选区旁的 inline AI → 预览 → 接受/取消 | 不偷偷改全文；失败不吞掉原文 |
| 处理 AI 建议或待办 | 建议/待办入口 → 查看依据 → 接受、完成或拒绝 | 状态可追踪，不因打开面板就自动写入 |
| 升级技能 | 查看已安装与可用版本 → 一键升级 | 目标目录明确；失败保留旧版与本地改动 |

## 交互原则

1. 从当前对象出发。文章任务默认取最后操作的可见笔记；切换侧栏或弹窗焦点不应悄悄换目标。没有笔记时先给清楚的创建或选择动作。
2. 首屏只展示下一步。写稿、排版和可选设置按任务渐进展开，技能名和内部参数不要求用户先理解。动作选择本身不发送 AI。
3. 窗口随内容和视口调整，保留可见的标题、关闭、主操作与错误反馈；窄窗可滚动，不能靠固定大尺寸压住编辑器。
4. 写入与发布据实报告。模型文字、预览、下载或打开外链均不能冒充文件写入或平台发布；实际工具回执决定完成状态。
5. 能力按宿主真实工具表达。视觉输入、生图、PNG、联网与外部发布分别判断；缺能力时说明可交付的提示词或 HTML 范围。
6. 笔记仍是 Markdown 文件真源。宿主只处理入口、当前笔记、预览与反馈；不再为写作增加平行数据库或一套重复方法论。

## 四仓职责

| 仓库 | 职责 | 本轮关注 |
|---|---|---|
| `topmind-skills` | 日常路由与工作区约定 | 单入口、平台技能直达、安装范围与升级保护 |
| `topmind-writing-skills` | 独立写作方法与宿主资源 | 少步骤安装/更新、状态可见、版本与本地改动保护 |
| `topmind` | Desktop 编辑器、AI Agent、建议、待办、inline AI | 首屏层级、目标绑定、明确开始、错误可见、响应式布局 |
| `topmind-obsidian` | Obsidian 原生入口、Vault 文件与弹窗 | Ribbon/工作台/上下文入口、新建后打开、原生尺寸与焦点 |

独立写作技能保持独立版本和发布。Desktop、Obsidian 的内置快照通过显式同步更新；正常构建不读取邻仓 HEAD。主技能负责通用工作区语义，明确平台稿优先已安装的独立技能。宿主提供真实工具，不把技能文本里的脚本说明当成可执行能力。

## 验收路径

- **入口**：从空工作区、已有笔记、选中文字三种起点走完；检查命令、Ribbon/工具栏/上下文入口名称一致、位置可发现。
- **写作**：选目的不发送；开始后目标不漂移；未保存稿件、无模型、无权限、能力缺失和执行失败有可见且可操作的反馈。
- **排版**：切换格式或主题使旧预览失效；复制与导出内容一致；预览不调用模型；本地图片和危险 URL 仍受既有围栏。
- **建议与待办**：查看、接受、拒绝、完成后状态一致；不自动从普通稿件写入稳定记忆或待办。
- **inline AI**：无选区、取消、失败、接受均保护原稿；替换只影响目标范围，必要时提示保存冲突。
- **尺寸与键盘**：宽桌面与约 430px 窄窗检查首屏、滚动、焦点、Esc、主按钮、错误提示和无横向溢出。
- **升级**：项目、全局、指定目录不串位；同版本跳过、新版本升级、已装更新版本拒绝降级；本地改动和无关同名目录不被静默覆盖。
- **发行**：四仓版本、变更记录、内置快照、测试和构建产物一致；仅在远端工作流及附件核对后称为已发版。

## 验证记录

- `topmind-skills`：`npm run pack`、`npm test` 通过（78 项）；安装器专项测试覆盖矩阵/单目录、复制/链接、冲突、升级、保留旧版和共享资源。
- `topmind-writing-skills`：`npm test`（11 项）与 `npm run check`（8 项独立技能）通过；宿主包资源和升级路径按包自身门禁校验。
- Desktop：`npm run desktop:quality` 通过，包含类型、i18n、测试、前端构建和打包资源校验。独立 Vite 组件审查覆盖 1280×800、430×800 的写作首屏及待办、建议异常状态；没有将临时审查页纳入发行源码。
- Obsidian：`npm run lint`、`npm run typecheck`、`npm test`（267 项）、`npm run build` 通过。独立临时 Vault 与本地模拟 Provider 的 [UI 冒烟记录](https://github.com/topmindspace/topmind-obsidian/blob/main/docs/UX-REVIEW-2026-10-28.md)覆盖 Ribbon、写作弹窗、选区审阅、建议/待办和新建笔记打开。冒烟宿主为 1.12.7，低于插件声明最低 1.13.0，只能证明本机 UI 路径，正式安装仍需受支持版本验证。

真实 Provider 的写作质量、微信/X 粘贴、Obsidian 主题矩阵与各平台安装包需在相应环境继续验收。既有 [写作集成说明](WRITING-INTEGRATION-AND-UPDATES-2026-10-26.md) 与 [文章任务契约](ARTICLE-TASK-EXECUTION-2026-10-27.md) 保留机制细节；本文维护用户路径和本轮验收结论。
