# Desktop 编辑器、交互与内容兼容整改

日期：2026-10-25。范围仅 Desktop 与对应文档；保留既有工作树，不改并行任务负责的根脚本、共享 AI 契约或 Obsidian 实现。

## 依据与实际问题

[Obsidian 官方语法说明](https://obsidian.md/help/obsidian-flavored-markdown)列出双链、嵌入、块引用、脚注、注释、高亮和 callout 等扩展；[内部链接说明](https://obsidian.md/help/links)还明确区分链接目标、标题与块定位。能打开 Markdown 文件，不等于能在另一编辑器里安全改写这些结构。

本项目仍使用现有 TipTap + `tiptap-markdown`。未因官方另有 [Markdown API](https://tiptap.dev/docs/editor/markdown/getting-started/basic-usage) 就直接更换解析链；先以真实保存结果判断是否丢失内容。

真实 Electron 复现：在含表格、双链、注释和脚注的文档末尾加入一段普通文本，旧实现把表格保存成连续文字，把双链转义，并改变脚注结构。因此本轮先修内容往返与保存反馈，再改善布局。

## 已实现

| 问题 | 整改 |
|---|---|
| 可视 schema 不支持的结构被重新序列化丢失 | 识别已知不安全语法后默认源码编辑，保留原文；禁用有损的可视切换，预览明确提示可能不完整 |
| 没有明确源码入口 | 原生具名模式按钮：编辑、Markdown 源码、预览；使用 aria-pressed，保留键盘访问 |
| 源码体验仍像普通表单 | 独占剩余编辑空间、单一滚动面、等宽字体，支持字号/行高、软换行、查找与大纲定位；不重复显示文章大标题 |
| 200% 缩放时 macOS 避让、导航与文件动作重叠 | 文件动作复用共享溢出轨道，按分配宽度恢复；窄画布的历史动作保留到菜单，纯图标使用 density 尺寸；祖先面包屑按容器宽度收起 |
| 保存失败切到加载错误页，重试可能重读磁盘丢草稿 | 保留文档与输入，显示原因和重试保存；不把写入失败当成读取失败 |
| 旧写入完成时把后续新编辑标成已保存 | 保存快照带文档代次和编辑版本，较早结果只能确认自身版本；未保存的新编辑继续保留 dirty 状态 |
| 排队时才读取当前文档，存在保存错文件风险 | 调用时捕获路径与内容；切文件读取等待离开文件的已排队写入，迟到结果不能回填新文档 |
| Markdown 序列化失败退化为纯文本 | 持久化启用严格模式；失败保留草稿，不把格式化文档压平成纯文本 |
| 未改动就保存也会重新格式化文件 | 直接保留已确认的原文件字节；源码保存保留 YAML 前缀、BOM 与统一 CRLF 行尾 |
| 保存后约 1.5 秒静默吞掉外部修改 | 删除 watcher 的路径时间静默及其调用方、废弃缓存与辅助函数；用实际内容比较识别回声 |
| 冲突对话框打开时仍可能自动覆盖磁盘 | 检查和待决冲突期间阻止保存；重叠读取按请求与文档代次隔离 |
| 所谓“合并”按行去重，破坏代码围栏、表格和重复内容 | 改为明确的“保留两份”，保留完整本地正文与完整磁盘正文，供用户审阅 |
| 源码/预览中的 AI 按钮发给未挂载的浮条，没有可见结果 | 先保存并挂载最新文件，再打开 AI 对话；可视模式继续使用选区 AI，不自动调用模型 |
| 属性异步更新可能回填已切走的文档 | 回调前后检查文档路径，当前输入继续保留 |
| 大纲误识别较长围栏内部标题，并改写单词中的下划线 | 复用围栏扫描与原文偏移，修复内部下划线清理；源码点击大纲可定位 |

模式切换本身不标脏。源码编辑的是正文，YAML 由现有属性面管理。图片语法能力复用 `embed-images.mjs`，未另建图片格式规则。前端仅新增一个纯文档模块，替换重复的保存与围栏逻辑。

## 验证范围

- 质量门前建立完整 Desktop 基线。
- 执行级测试覆盖：旧保存与新编辑、失败后同内容重试、快照捕获、同路径新代次隔离、严格序列化、围栏与查找、BOM/CRLF、模式按钮、历史控件状态、按分配宽度收起/恢复文件动作和完整正文冲突保留。
- 真实监听测试通过实际 Desktop 写路径保存，再立即由外部写入文件；先在旧时间静默逻辑下复现失败，再移除静默后通过。
- 真实 Electron 使用隔离的临时状态与工作区：源码自动选择、模式往返、表格/双链/脚注保留、只读目录故障与重试、外部冲突、跨过自动保存间隔仍保留磁盘、保留两份完整表格、AI 上下文最新内容、无改动保存、BOM/CRLF、源码大纲、清空后切文件落盘、中文深色最小窗口和 200% 缩放。真实几何断言覆盖顶栏/格式条按钮互不重叠、面包屑不侵入文件名；菜单动作可达，关闭 AI 列后动作恢复。

最终根集成质量门 `npm run validate` 通过：Kernel **692**、UTR **151**、Desktop **1468 + 77** 项测试全部通过；类型、语法、未声明标识符、废弃代码、双语键、构建与 **12 项打包源码检查**通过。真实 Electron 的 **13 项交互检查**通过，渲染器异常为零。打包检查未发现现成安装包，只验证源码与资源准备，不代表发行安装包验收。

这些测试不使用生产内容、凭据或付费模型。主机上的外部文件写入模拟 Obsidian 的落盘行为，没有启动 Obsidian 桌面应用。
