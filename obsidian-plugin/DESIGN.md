# topmind Obsidian Plugin — UI/UX 设计

> **设计北极星**：最低摩擦个人动态流 — 在 Obsidian 中随手记下、AI 默认建议、用户确认后沉淀、文件永远是你的。
> **用户概念 ≤5**：记一下 · 动态 · 专题 · 我的情况 · 写出来
> **Obsidian-native 优先**：复用 Obsidian 原生能力，不重建编辑器/文件树/命令面板。

---

## 1. 入口形态

### 1.1 三入口架构

```text
┌──────────────────────────────────────────────────────────────┐
│  入口 1: 主区域工作台 (Stream Workbench View)                  │
│  ────────────────────────────────────────────────────────    │
│  Obsidian 中央主编辑区的独立页签 (ItemView / Tab)               │
│  宽屏视野 · 高频主空间                                          │
│  承载：极速输入 + 动态卡片流 + AI 涌现建议                       │
├──────────────────────────────────────────────────────────────┤
│  入口 2: 侧边栏小组件 (Sidebar Dock View)                      │
│  ────────────────────────────────────────────────────────    │
│  右侧/左侧 Leaf，宽约 250px                                    │
│  承载：今日待办快捷勾选 + 最近 3 条动态 + 召唤主工作台           │
├──────────────────────────────────────────────────────────────┤
│  入口 3: 极速捕捉弹窗 (Quick Capture Modal)                    │
│  ────────────────────────────────────────────────────────    │
│  Ribbon 图标触发（快捷键需在 Settings → Hotkeys 自行配置）       │
│  零阻碍输入 → Enter 提交 → 静默写入周期本 → 关闭                │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 与用户原方案的差异与优化

| 原方案 | 优化后 | 理由 |
|--------|--------|------|
| 主区域承载"多模态卡片、时间轴、专题看板、交付展示" | 主区域聚焦动态流 + AI 建议 | MVP 不宜全量复刻 Desktop；专题/交付用 Obsidian 原生 |
| 重建富文本编辑器 | 复用 Obsidian 原生 Markdown 编辑器 | 不重建 Tiptap；双击卡片即可在 Obsidian 中编辑 |
| 重建文件树/命令面板 | 复用 Obsidian 原生文件树 + ⌘P | 避免重复造轮子 |
| AI 作为独立面板 | AI 建议内联在动态流中 | 副驾不喧宾夺主；建议卡片在流中呈现 |

### 2.2 交互细节

| 元素 | 交互 |
|------|------|
| 输入栏 | 多行 textarea；`Enter` 提交（`Shift+Enter` 换行）；提交后清空 + 刷新流 |
| 动态卡片 | 默认折叠摘要；点击展开全文；`双击` → 在 Obsidian 编辑器中打开周期本并定位（Roadmap：当前仅展开/折叠） |
| 周期切换 | 下拉选择历史周期本；显示日期范围 |
| AI 建议卡片 | 多种类型：`create_topic`（专题涌现）/ `promote_memory`（写入「我的情况」）/ `ai_summary`（周期摘要）/ `inbox_review`（收件箱待整理）/ `stale_topic`（陈旧专题）/ `catch_all`（兜底清理）/ `stream_digest`（周期摘要）/ `open_profile`（完善「我的情况」）；`确认` → 经 writeback-engine 执行；`忽略` → 移除卡片 |
| 整理按钮 | `reconcilePeriodBody`（合并散落条目）+ 可选 `todo_maintain`（AI 提取待办）+ 刷新 AI 建议 |
| 自动刷新 | 监听 Vault 文件变更；450ms 防抖静默重载 |

### 2.3 视觉风格

- 使用 Obsidian CSS 变量（`--text-normal`, `--background-primary`, `--interactive-accent` 等）
- 卡片样式：圆角 + 微阴影 + hover 高亮
- 输入栏：单行高度起，自适应增长
- AI 建议卡片：左侧带彩色边条（蓝=create_topic/inbox_review，橙=todo_extract/stale_topic/catch_all，绿=promote_memory/open_profile，紫=ai_summary/stream_digest）
- 全中文 UI（可切英文）

## 3. 侧边栏小组件 (Sidebar Dock View)

### 3.1 布局

```text
┌─────────────────────────┐
│ 🌊 Topmind              │  ← 标题
├─────────────────────────┤
│                          │
│ ── 今日待办 ──────────── │
│ ☐ 研究插件架构           │
│ ☑ 写设计文档             │
│ ☐ 测试 writeback        │
│                          │
│ ── 最近动态 ──────────── │
│ 15:30 讨论了插件架构...  │
│ 14:00 阅读了 API 文档... │
│ 12:00 记下了开发计划...  │
│                          │
│ ┌─────────────────────┐ │
│ │  打开主工作台  →    │ │  ← 召唤按钮
│ └─────────────────────┘ │
│                          │
└─────────────────────────┘
```

### 3.2 交互

- 待办项：点击勾选 → `toggleTodoItem` → 刷新
- 动态条目：点击 → 跳转到主工作台并高亮对应卡片
- 召唤按钮：`workspace.getLeaf().setViewState({ type: VIEW_TYPE_STREAM_WORKBENCH })`
- 自动刷新：Vault 事件监听（modify / create）+ 450ms 防抖；路径过滤只关注动态目录和 memory/todo.md

## 4. 极速捕捉弹窗 (Quick Capture Modal)

### 4.1 布局

```text
┌──────────────────────────────────────────┐
│  ⚡ 记一下                          [×]  │
├──────────────────────────────────────────┤
│                                           │
│  ┌──────────────────────────────────┐    │
│  │  （在此输入...）                  │    │
│  │                                    │    │
│  └──────────────────────────────────┘    │
│                                           │
│  目标: [本周动态 ▾]   标签: #...         │
│                                           │
│  ⏎ 提交    ⇧⏎ 换行    Esc 关闭           │
│                                           │
└──────────────────────────────────────────┘
```

### 4.2 交互

- 打开即聚焦输入框；零阻碍
- `Enter` 提交 → `KernelService.capture(text, { target, tags })` → writeback-engine → 关闭
- 目标选择：本周动态（默认）/ 收件箱
- 标签解析：`#标签` 自动提取为 frontmatter tags
- 提交后：Notice 提示写入路径；若主工作台打开则刷新

## 10. 暗色模式

所有颜色使用 Obsidian CSS 变量，自动适配暗色模式：

```css
.tm-card {
  background: var(--background-secondary);
  color: var(--text-normal);
  border: 1px solid var(--background-modifier-border);
}
.tm-card:hover {
  background: var(--background-modifier-hover);
}
```
