B · 本机工作区（无需 Desktop 运行）

离线可用

选择你的 topmind-workspace 根目录（含 00-收件箱 等）。浏览器会请求读写权限；笔记按规约写入 Inbox，frontmatter 与 capture 一致。

工作区：未配置

需 Chromium（Chrome / Edge）。选择文件夹后，请在本页点一次「重新授权写入」或直接去弹窗点「剪藏」—— 浏览器会记住权限；Service Worker 不能自行弹授权框。工作区直写与 Bridge 共用同一 HTML→MD；Bridge 另提供落点列表并走 Desktop 写闸。

C · 剪藏模板

按 URL 自动匹配（非 Obsidian 完整 DSL）。内置：article · selection · bookmark · github · zhihu。变量：title url author published site content selection highlights。

自定义模板：0 · 内置：5

也可粘贴 {"templates":[...]}。自定义模板优先于内置域名匹配（同 id 覆盖）。Bridge 在线时可在 popup 选择 Inbox / 类别 / 专题落点。
